# 极光一键认证原生组件

本轮构建将 `@kuikly-open/render` 固定为既有基线 `2.29.1`，避免安装时因范围解析升级 Renderer；厂商 SDK 与公开 API 不变。

> 当前渠道版本和候选状态见[README](../../README.md#渠道版本)。

2026-10-08 当前源码与三端边界见[功能与平台差异](../../docs/功能与平台差异.md)；本包只承担上文所述原生能力，以下版本和渠道记录按各自日期阅读。

提供 GycJVerificationService 与 GycJVerificationModule，宿主接线参阅仓库根 README。

```sh
ohpm install @gycrosskit/jverification-native@1.0.2
```
